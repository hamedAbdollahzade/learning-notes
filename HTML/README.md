# آموزش کامل HTML (مبتدی تا پیشرفته)

HTML (HyperText Markup Language) زبان **ساختار** صفحه‌ی وبه: مشخص می‌کنه محتوا چیه (تیتر، پاراگراف، لینک، فرم، ...). ظاهر رو CSS و رفتار رو JavaScript تعیین می‌کنه.

> برای تمرین: یک فایل `index.html` بساز، با مرورگر باز کن و بعد از هر تغییر صفحه رو Refresh کن. یا از VS Code + افزونه‌ی Live Server استفاده کن.
