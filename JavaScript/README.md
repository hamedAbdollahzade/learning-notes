# آموزش کامل جاوا اسکریپت (از صفر تا پیشرفته)

این پوشه یک مسیر یادگیری مرحله‌به‌مرحله‌ی JavaScript است. هر فایل شامل توضیح، مثال و خروجی مورد انتظار است. کدها با Node.js (نسخه‌ی ۲۰ به بالا) یا کنسول مرورگر قابل اجرا هستن.

> قرارداد: `// →` در کد یعنی «خروجی یا مقدار نتیجه».

## چطور استفاده کنم؟
- همه‌ی کدها رو خودت بنویس و اجرا کن (`node file.js`). خوندن کافی نیست.
- هر فایل رو که تموم کردی، چند تمرین کوچیک از خودت بساز.
- ترتیب فایل‌ها طوریه که هر کدوم روی قبلی ساخته می‌شه.
